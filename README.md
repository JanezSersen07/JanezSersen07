## 🚀 Proyectos

### 🧾 Sistema de ventas Mateverso
Programa de consola en **C#** que uso para llevar las ventas de mi emprendimiento: reemplazó mi planilla de Google Sheets. Importa la planilla, guarda los datos en un archivo, controla el estado de cada venta (pedido, pagado, entregado) y calcula ganancias por mes y por medio de pago.

**Tecnologías:** C#, programación orientada a objetos, manejo de archivos CSV
**Código:** [ver repositorio](https://github.com/JanezSersen07/sistema-pedidos-mateverso)

### 🛍️ Catálogo Mateverso
Catálogo online con más de 160 productos, con buscador y filtro por categoría. Los datos se cargan desde un archivo JSON.

**Tecnologías:** HTML, CSS, JavaScript (fetch, async/await)
**Sitio:** [ver online](https://janezsersen07.github.io/catalogo-mateverso/) · **Código:** [ver repositorio](https://github.com/JanezSersen07/catalogo-mateverso)

### 🔗 Links de Mateverso
Página de links del emprendimiento, pensada para el celular: tienda, WhatsApp y redes en un solo lugar.

**Tecnologías:** HTML, CSS
**Sitio:** [ver online](https://janezsersen07.github.io/links-mateverso/) · **Código:** [ver repositorio](https://github.com/JanezSersen07/links-mateverso)
