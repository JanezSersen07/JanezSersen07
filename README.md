## 🚀 Proyectos

### 🧾 Sistema de ventas Mateverso
Programa de consola en **C#** que uso para llevar las ventas de mi emprendimiento: reemplazó mi planilla de Google Sheets. Importa la planilla, guarda los datos en un archivo, controla el estado de cada venta (pedido, pagado, entregado) y calcula ganancias por mes y por medio de pago.

**Tecnologías:** C#, programación orientada a objetos, manejo de archivos CSV
**Código:** [ver repositorio](https://github.com/JanezSersen07/sistema-pedidos-mateverso)

### ⚽ Argentina en la historia: análisis de datos
Análisis en Python de más de 49.900 partidos de selecciones de fútbol (1872–2026): cómo le fue a Argentina por década y quiénes son sus máximos goleadores. Incluye limpieza de datos, visualizaciones y una sección de limitaciones del dataset.

**Tecnologías:** Python, pandas, matplotlib, Google Colab
**Notebook:** [ver en Colab](https://colab.research.google.com/github/JanezSersen07/analisis-seleccion-argentina/blob/main/analisis-argentina.ipynb) · **Código:** [ver repositorio](https://github.com/JanezSersen07/analisis-seleccion-argentina)

### 🗄️ Base de datos Mateverso (Oracle SQL y PL/SQL)
Base de datos relacional para un emprendimiento de ventas: modelo con claves y restricciones, vista de ganancias, 11 consultas (JOIN, GROUP BY, subconsultas, funciones de ventana) y PL/SQL con procedimientos, función y un trigger que valida y descuenta el stock en cada venta.

**Tecnologías:** Oracle Database, SQL, PL/SQL
**Código:** [ver repositorio](https://github.com/JanezSersen07/base-de-datos-mateverso)
